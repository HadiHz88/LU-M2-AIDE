# Part 2, step 3 (branch features/netlify) — real deployment + smoke test.
# Moved to a "deploy" stage so it runs AFTER the build and receives build/.
# Fixes vs the PDF:
#   * node:22-alpine, because the PDF's `apk add curl` does not work on the
#     Debian-based node:23-slim image.
#   * --no-build: current netlify-cli builds before deploying by default; we
#     deploy the artifact that build_website already produced.
#   * the smoke test hits YOUR site, not the professor's.
stages:
  - build
  - test
  - deploy

variables:
  NETLIFY_SITE_ID: "REPLACE-WITH-YOUR-SITE-ID"
  NETLIFY_SITE_NAME: "REPLACE-WITH-YOUR-SITE-NAME"   # the part before .netlify.app

build_website:
  image: node:23-slim
  stage: build
  script:
    - node --version
    - npm --version
    - npm ci
    - npm run build
  artifacts:
    paths:
      - build/

test_artifact:
  image: alpine
  stage: test
  script:
    - test -f build/index.html

unit_tests:
  image: node:22-alpine
  stage: test
  script:
    - npm ci
    - npm test
  artifacts:
    when: always
    reports:
      junit: reports/junit.xml

netlify_deploy:
  stage: deploy
  image: node:22-alpine
  script:
    - npm install -g netlify-cli@27
    - netlify --version
    - apk add --no-cache curl
    - netlify status
    - echo $NETLIFY_SITE_ID
    - netlify deploy --alias uat --dir build --no-build
    - curl -fsS "https://uat--${NETLIFY_SITE_NAME}.netlify.app/" | grep 'GitLab'
    - echo "End of deployment"

aws_s3:
  stage: deploy_aws
  image:
    name: amazon/aws-cli
    entrypoint: [""]          # the image's entrypoint is `aws`; GitLab needs a shell
  rules:
    - if: $CI_COMMIT_REF_NAME == $CI_DEFAULT_BRANCH
  needs:
    - build_website           # start as soon as the build exists (doesn't wait for the manual prod job)
  script:
    - aws --version
    - aws s3 ls
    - echo "Bucket content BEFORE upload:"
    - aws s3 ls "s3://$AWS_S3_BUCKET" --recursive
    - aws s3 sync ./build/ "s3://$AWS_S3_BUCKET" --delete
    - echo "Bucket content AFTER upload:"
    - aws s3 ls "s3://$AWS_S3_BUCKET" --recursive
    - echo "Website -> http://$AWS_S3_BUCKET.s3-website-$AWS_DEFAULT_REGION.amazonaws.com/"

SymptomCause / fix
Pipeline stays pending / asks to verifyAccount not validated for shared runners: verify on gitlab.com, or enable instance runners in Settings -> CI/CD -> Runners.
YAML error: jobs config should contain..., mapping values are not allowedIndentation. Paste the file again exactly; spaces only (whitespace rendering helps).
netlify status: Not logged inNETLIFY_AUTH_TOKEN missing, misspelled, or marked Protected while on a feature branch.
netlify deploy starts building / vite: not foundMissing --no-build. Use the provided files.
curl: (22) ... 404 or grep finds nothingWrong NETLIFY_SITE_NAME (it's the part before .netlify.app).
apk: not foundapk only exists on alpine images; deploy jobs use node:22-alpine.
Merge button: must be rebasedFast-forward merge needs the branch up to date: click Rebase on the MR.
netlify_uat / netlify_prod missingExpected on feature branches (rules: main only). They appear on the main pipeline after merging.
Commit to main refusedExpected after step 1.10. Commit to a new branch.
InvalidAccessKeyId / SignatureDoesNotMatchAWS variables wrong (extra space, swapped).
AccessDenied on aws s3 lsIAM user lacks the S3 policy (or ListAllMyBuckets in the least-privilege policy).
S3 site: 403 ForbiddenBlock public access still on, or bucket policy ARN has the wrong bucket name.
S3 site: 404Static website hosting not enabled, or index document not index.html, or the sync hasn't run.
Variable can't be maskedValue must be 8+ characters on one line. Netlify tokens and AWS keys are fine.
