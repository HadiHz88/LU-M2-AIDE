PART 1 · LECTURES 03–04

Backpropagation by hand

Start with one neuron to see the chain rule, then do the full Lecture 03 example (slides 47–58).

1.1 Warm-up: one sigmoid neuron

Given

Input \(x = 1.5\), weight \(w = 0.8\), bias \(b = -0.2\), target \(t = 1\), learning rate \(\eta = 0.5\). Sigmoid activation, error \(E = \tfrac12 (t - o)^2\).

The whole idea of backprop is in one line. The error depends on \(w\) only through a chain \(w \to z \to o \to E\), so you multiply the three local derivatives:

\[\frac{\partial E}{\partial w} = \underbrace{\frac{\partial E}{\partial o}}_{(o-t)} \cdot \underbrace{\frac{\partial o}{\partial z}}_{o(1-o)} \cdot \underbrace{\frac{\partial z}{\partial w}}_{x}\]
forward\(z = 0.8 \cdot 1.5 - 0.2 = 1.0\),  \(o = \sigma(1.0) = 0.731058579\)
error\(E = \tfrac12(1 - 0.731058579)^2 = 0.036164744\)
∂E/∂o\(o - t = -0.268941421\)
∂o/∂z\(o(1-o) = 0.731058579 \cdot 0.268941421 = 0.196611933\)
δ = ∂E/∂z\(-0.268941421 \cdot 0.196611933 = -0.052877093\)
∂E/∂w\(\delta \cdot x = -0.052877093 \cdot 1.5 = -0.079315639\)
∂E/∂b\(\delta \cdot 1 = -0.052877093\)
update\(w^+ = 0.8 - 0.5(-0.079315639) = 0.839657820\),  \(b^+ = -0.2 - 0.5(-0.052877093) = -0.173561454\)

The gradient is negative, so the weight goes up. That makes sense: the output is too low (0.73 vs 1), and a bigger weight pushes it higher.

The quantity \(\delta\), the error at a neuron's input, is the thing you will carry backwards through a network. Once you have a neuron's \(\delta\), the gradient for any weight coming into it is just \(\delta \times\) whatever that weight multiplies.

1.3 Variations the exam can throw at you

The method above never changes. Only one of the three chain-rule factors changes.

If the question says…What changes
Update the biases tooA bias is a weight whose input is always 1. So \(\partial E/\partial b = \delta\), summed over every neuron that shares it. In the example: \(\partial E/\partial b_2 = \delta_{o1} + \delta_{o2} = 0.100400325\), and \(\partial E/\partial b_1 = \delta_{h1} + \delta_{h2} = 0.018725609\).
Linear output (regression; Lecture 03, Example 1)\(f'(net) = 1\), so \(\delta_o = o - t\).
Sigmoid with slope a: \(f = 1/(1+e^{-a x})\)\(f' = a\, f(1-f)\). Multiply every \(o(1-o)\) by \(a\).
tanh\(f' = 1 - f^2\) (use the output value, not the net value).
ReLU\(f' = 1\) if net > 0, else 0. A neuron with net ≤ 0 passes no error back.
Error written as \(\tfrac12(t-o)^2\) with \(\Delta w = +\eta\,\delta\,x\)The same rule with the sign flipped: here \(\delta = (t - o) f'\). Pick one convention and keep it through the whole problem.
Mean error over N samples: \(\tfrac{1}{2N}\sum\)Batch learning: compute the gradient for each sample, average them, then do one update.

Softmax with cross-entropy

Scores \(z = (2.0,\ 1.0,\ 0.1)\), true class is the first one, so \(t = (1, 0, 0)\).

exponentials\(e^{2} = 7.389056,\ e^{1} = 2.718282,\ e^{0.1} = 1.105171\), sum \(= 11.212509\)
softmax\(p = (0.659001,\ 0.242433,\ 0.098566)\), which sums to 1
loss\(-\ln p_{true} = -\ln 0.659001 = 0.417030\)
δ = p − t\((-0.340999,\ 0.242433,\ 0.098566)\)

Remember this result: with softmax and cross-entropy together, the output \(\delta\) is just \(p - t\). There is no extra derivative factor, so this pair does not suffer from the slow learning that sigmoid with squared error has when the output saturates.

Momentum, two steps

\(w_0 = 1.0\), \(\eta = 0.1\), \(\beta = 0.9\), \(v_0 = 0\). Gradients at steps 1 and 2: 0.4 and 0.3.

rule\(v_t = \beta v_{t-1} - \eta\, g_t, \quad w_t = w_{t-1} + v_t\)
step 1\(v_1 = 0.9(0) - 0.1(0.4) = -0.04, \quad w_1 = 0.96\)
step 2\(v_2 = 0.9(-0.04) - 0.1(0.3) = -0.066, \quad w_2 = 0.894\)

Plain gradient descent would reach 0.93 after these two steps. Momentum gets further (0.894) because the first step's velocity carries over.

Where marks are lost

  • Using the updated \(w_5\dots w_8\) when computing hidden deltas. Always use the old weights.
  • For a hidden neuron, forgetting to sum the error coming back from every output it feeds.
  • Computing \(\sigma'(net)\) as \(net(1-net)\). It is \(out(1-out)\): use the neuron's output.
  • Multiplying \(\delta\) by the wrong input. For \(w_5\) the input is \(h_1\) (the neuron the weight comes from), not \(i_1\).
  • Rounding to 2–3 decimals early. Hidden-layer gradients here are around 0.0004, so keep at least 6 significant figures.

2.4 The output-size formula and its edge cases

\[O = \left\lfloor \frac{W - K + 2P}{S} \right\rfloor + 1\]

\(W\) = input width (or height), \(K\) = kernel size, \(P\) = padding on each side, \(S\) = stride. Apply it to height and width separately if they differ. Pooling uses the same formula.

2.7 How a CNN is trained

  • Same backprop as Part 1. A conv layer is a layer of neurons with shared weights and local connections.
  • Shared weights: a kernel weight is used at every position, so its gradient is the sum of the gradients from all positions.
  • Max pooling: the gradient goes only to the cell that was the maximum in each window. The other cells get 0. Average pooling splits it equally.
  • Transfer learning (Lecture 05): take a network pretrained on a big dataset. With a small dataset similar to the original, freeze the conv layers and retrain only the new classifier head. With more data or a different domain, also fine-tune the top layers with a small learning rate.

PART 3 · LECTURE 07

RNNs by hand, from zero

An RNN is one small network applied at every time step, passing a memory \(h\) from each step to the next. Everything below uses scalars so you can do it on paper.

3.1 The idea and the equations

A feed-forward network sees one input and forgets it. For sequences (text, speech, time series) the meaning depends on order and context. An RNN keeps a hidden state \(h_t\) that summarises everything seen so far, and updates it at each step:

\[h_t = \tanh(W_{xh}\, x_t + W_{hh}\, h_{t-1} + b) \qquad y_t = W_{hy}\, h_t\]
  • The same weights \(W_{xh}, W_{hh}, W_{hy}\) are used at every time step. That is what lets it handle sequences of any length.
  • \(h_0\) is usually 0.
  • "Unrolling" means drawing one copy of the network per time step, linked by \(h\). An unrolled RNN is just a deep feed-forward network with shared weights.
TypeInput → outputExample
One-to-one1 → 1Ordinary classification (not really recurrent)

3.3 Backpropagation through time (BPTT)

Unroll the network, then backprop exactly as in Part 1, from step 3 back to step 1. Two new things:

  • The error reaches \(h_{k-1}\) through \(h_k\): \(\ \partial E/\partial h_{k-1} = \delta_k \cdot w_h\), where \(\delta_k = \partial E/\partial h_k \cdot (1 - h_k^2)\) (tanh derivative).
  • Because \(w_h\) is used at every step, its gradient is the sum over the steps: \(\ \partial E/\partial w_h = \sum_k \delta_k\, h_{k-1}\). Same for \(w_x\): \(\sum_k \delta_k\, x_k\).

Update as usual, \(w \leftarrow w - \eta\,\partial E/\partial w\). (These values were checked against a numerical gradient.)

Why RNNs forget: vanishing and exploding gradients

Look at the \(\partial E/\partial h_k\) column: each step back multiplies by \(w_h (1 - h_k^2)\). Here those factors are 0.79, 0.49 and 0.57, so the signal from step 3 shrinks fast. Over 20 steps with a factor around 0.4: \(0.4^{20} \approx 10^{-8}\). The early inputs get almost no gradient, so the network cannot learn long-range dependencies. If the factor is above 1 (say 1.5), it explodes instead: \(1.5^{20} \approx 3{,}325\).

  • Exploding: fixed with gradient clipping (cap the gradient's size).
  • Vanishing: fixed by changing the cell: LSTM and GRU.

3.4 One LSTM step

An LSTM adds a second memory, the cell state \(c_t\), and three gates. Each gate is a sigmoid between 0 (block) and 1 (let through).

\[\begin{aligned} f_t &= \sigma(W_f x_t + U_f h_{t-1} + b_f) && \text{forget: how much old memory to keep}\\ i_t &= \sigma(W_i x_t + U_i h_{t-1} + b_i) && \text{input: how much new info to write}\\ \tilde c_t &= \tanh(W_c x_t + U_c h_{t-1} + b_c) && \text{candidate: the new info itself}\\ o_t &= \sigma(W_o x_t + U_o h_{t-1} + b_o) && \text{output: how much memory to show}\\ c_t &= f_t \odot c_{t-1} + i_t \odot \tilde c_t \qquad h_t = o_t \odot \tanh(c_t) \end{aligned}\]
Given

\(x_t = 1,\ h_{t-1} = 0.5,\ c_{t-1} = 0.8\). Weights \((W, U, b)\): forget \((0.5, 0.5, 0)\), input \((1, -1, 0)\), candidate \((0.8, 0.4, 0)\), output \((0.5, 1, -0.5)\).

forget\(f = \sigma(0.5 + 0.25) = \sigma(0.75) = 0.679179\)
input\(i = \sigma(1 - 0.5) = \sigma(0.5) = 0.622459\)
candidate\(\tilde c = \tanh(0.8 + 0.2) = \tanh(1.0) = 0.761594\)
output gate\(o = \sigma(0.5 + 0.5 - 0.5) = \sigma(0.5) = 0.622459\)
cell\(c = 0.679179(0.8) + 0.622459(0.761594) = 0.543343 + 0.474061 = 1.017404\)
hidden\(h = 0.622459 \cdot \tanh(1.017404) = 0.622459 \cdot 0.768807 = 0.478551\)

Why this fixes vanishing gradients: the cell state is updated by addition (\(f \cdot c_{t-1} + \dots\)), not by squashing it through a weight matrix and a tanh at every step. Going back one step, the gradient along the cell path is just multiplied by \(f\). When the forget gate stays near 1, the gradient passes through many steps almost unchanged.

3.5 One GRU step

A GRU merges the cell and hidden state and uses only two gates, so it has fewer parameters and is faster. It usually performs about as well as an LSTM.

\[\begin{aligned} z_t &= \sigma(W_z x_t + U_z h_{t-1}) && \text{update gate}\\ r_t &= \sigma(W_r x_t + U_r h_{t-1}) && \text{reset gate}\\ \tilde h_t &= \tanh(W x_t + U (r_t \odot h_{t-1})) && \text{candidate}\\ h_t &= (1 - z_t)\odot h_{t-1} + z_t \odot \tilde h_t \end{aligned}\]

Same \(x_t = 1,\ h_{t-1} = 0.5\). Update gate weights \((0.5, 0.5)\), reset \((1, -1)\), candidate \((0.8, 0.4)\).

update\(z = \sigma(0.75) = 0.679179\)
reset\(r = \sigma(0.5) = 0.622459\),  \(r \cdot h_{t-1} = 0.311230\)
candidate\(\tilde h = \tanh(0.8 + 0.4 \cdot 0.311230) = \tanh(0.924492) = 0.728015\)
hidden\(h = (1 - 0.679179)(0.5) + 0.679179(0.728015) = 0.654863\)

Some books swap the roles: \(h_t = z_t \odot h_{t-1} + (1-z_t)\odot\tilde h_t\). Both are correct; use the one in your exam statement.

3.6 Parameter counts and the variants

For input size \(x\) and hidden size \(h\), one vanilla RNN cell has \(h\cdot x\) (input weights) \(+\ h\cdot h\) (recurrent weights) \(+\ h\) (bias). An LSTM has 4 such blocks (3 gates + candidate); a GRU has 3.

CellFormulax = 10, h = 20
Vanilla RNNh(x + h) + h200 + 400 + 20 = 620

GRU3 · [h(x + h) + h]1,860
Bidirectional (any cell)2 × the celle.g. BiLSTM 4,960
  • Bidirectional RNN / BiLSTM: one RNN reads left to right, another right to left, and their hidden states are concatenated. Each position then sees past and future context. It needs the whole sequence up front, so it doesn't work for real-time generation.
  • Encoder-decoder: the encoder reads the whole input and its final hidden state becomes a fixed-size context vector. The decoder generates the output from it. The weakness: one fixed vector must hold an entire long sentence (the bottleneck).

3.7 Attention, one step by hand

Attention removes the bottleneck. At each output step, the decoder looks back at all encoder states and takes a weighted average, with weights chosen by relevance.

Given

Encoder states \(h_1 = (1, 0),\ h_2 = (0, 1),\ h_3 = (1, 1)\). Current decoder state (the query) \(s = (1, 2)\). Dot-product scores.

1 · scores\(s\cdot h_1 = 1,\quad s\cdot h_2 = 2,\quad s\cdot h_3 = 3\)
2 · softmax\(e^1, e^2, e^3 = 2.718, 7.389, 20.086\), sum \(30.193\), so \(\alpha = (0.090,\ 0.245,\ 0.665)\)
3 · context\(c = 0.090(1,0) + 0.245(0,1) + 0.665(1,1) = (0.755,\ 0.910)\)

The decoder pays most attention to \(h_3\), the state most aligned with its query. The context \(c\) is then fed into the decoder along with \(s\).

Self-attention (the core of Transformers) does the same thing within one sequence: every position builds a query \(Q\), a key \(K\) and a value \(V\) from its own vector, and attends to every other position:

\[\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right) V\]

Dividing by \(\sqrt{d_k}\) keeps the scores from growing with the vector size, which would make the softmax too peaked. Scaled, the example above becomes scores \((0.707, 1.414, 2.121)\), weights \((0.140, 0.284, 0.576)\): a softer spread. Unlike an RNN there's no step-by-step recurrence, so all positions are computed in parallel.

Where marks are lost

  • Forgetting that the RNN weights are shared, so the gradient is a sum over time steps.
  • Using \(\sigma'\) instead of \(\tanh' = 1 - h^2\) for the hidden state.
  • Counting LSTM parameters with 3 blocks instead of 4. The candidate \(\tilde c\) has weights too.
  • Saying LSTMs fix exploding gradients. They mainly fix vanishing ones; exploding is handled by clipping.
